# 루틴 프롬프트

오늘은 {{today}} 입니다. 아래 순서로 작업해주세요.

1. 오늘 요일(월~금)을 확인한다. 주말이면 아무 것도 하지 말고 종료한다.

2. 이번 주 월요일 날짜를 계산한다. 저장소의 `menu.json` 파일을 확인한다.
   - 파일이 없거나, 파일 안의 `week_of` 값이 이번 주 월요일과 다르면 → 3번으로 진행 (새로 분석 필요)
   - 파일이 있고 `week_of`가 이번 주 월요일과 같으면 → 4번으로 바로 진행 (이미 분석됨)

3. (새로 분석이 필요한 경우) Google Drive에서 "구내식당메뉴" 폴더를 찾아, 가장 최근에 업로드된 이미지 파일을 찾는다.
   - 그 이미지를 열어서 분석한다. 이미지는 월~금 메뉴가 표 형태로 되어 있다.
   - 요일별 메뉴를 텍스트로 정리해서 아래 형식으로 `menu.json`에 저장(덮어쓰기)한다:
     ```json
     {
       "week_of": "이번 주 월요일 날짜 (YYYY-MM-DD)",
       "menu": {
         "월": "월요일 메뉴 내용",
         "화": "화요일 메뉴 내용",
         "수": "수요일 메뉴 내용",
         "목": "목요일 메뉴 내용",
         "금": "금요일 메뉴 내용"
       }
     }
     ```
   - 이미지를 찾지 못했다면, 카카오 메시지로 "이번 주 메뉴표 이미지를 Google Drive에서 찾지 못했습니다. 확인해주세요." 라고 보내고 종료한다.

4. `menu.json`에서 오늘 요일에 해당하는 메뉴를 꺼낸다.

5. 아래와 같은 형식으로 메시지를 만든다:
   ```
   🍚 오늘의 구내식당 메뉴 ({{today}})

   {오늘 메뉴 내용}
   ```

6. 저장소 루트에 있는 `send_kakao.sh`를 실행해서 메시지를 전송한다:
   ```
   bash send_kakao.sh "메시지 내용"
   ```

7. 만약 `send_kakao.sh` 실행 결과에 "새 refresh_token을 발급했습니다"라는 경고가 나오면, 그 값을 실행 로그에 그대로 남겨서 사용자가 확인할 수 있게 한다.
