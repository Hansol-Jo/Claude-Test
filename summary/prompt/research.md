[목표]
'{prompt-path}' 프롬프트를 참조하여 프로젝트 스콥으로 '{skill-name}' 스킬 제작

[역할]
당신은 페르소나 기반의 스킬 제작 전문가임

[맥락]
프롬프트의 재사용을 편리하게 하기 위해 스킬을 제작하고 싶음

[입력]
-{prompt-path}: {사용자가 입력한 상대경로}
-{skill-name}: {사용자가 입력한 스킬명}

[처리]
1. {prompt-path} 또는 {skill-name}이 비어있으면 AskUserQuestion을 사용하여 나에게 요청
   - {prompt-path}는 현재 프로젝트 루트 기준 상대경로로 입력받음
2. {prompt-path}의 프롬프트 내용을 읽고 이해
   - 목적, 처리 흐름, 필요한 파일/코드 조작 여부를 파악
3. 파악한 내용을 바탕으로 허용 도구 / 금지 도구를 정의
   - 프롬프트 수행에 실제로 필요한 동작(예: 파일 읽기/쓰기, 코드 실행, 웹 검색 등)만 허용 도구로 지정
   - 불필요하거나 위험 소지가 있는 동작은 금지 도구로 명시
4. 원본 프롬프트를 본문에 반영하되, 프롬프트 작성 가이드를 준용하여 재작성
   - 원본의 핵심 목적·지시사항·제약조건은 임의로 변경·생략하지 않음
   - 모호한 표현은 명확한 지시문으로 다듬되 의미는 보존
5. 위 내용을 종합하여 스킬 파일(SKILL.md) 작성

[출력]
-스킬: `.claude/skills/{skill-name}/SKILL.md`

[제약조건]
-MUST:
 -Frontmatter에 name, description, 허용 도구, 금지 도구 명시
 -본문의 프롬프트는 프롬프트 작성 가이드 준용
 -허용/금지 도구는 원본 프롬프트의 실제 필요 동작을 근거로 판단하여 정의
-MUST NOT:
 -{prompt-path} 또는 {skill-name} 값을 임의로 추측·생성하지 말 것
 -원본 프롬프트의 핵심 목적이나 지시사항을 임의로 변경·생략하지 말 것
 -프롬프트 내용상 근거 없는 도구를 허용 도구로 추가하지 말 것

[완료조건]
-`.claude/skills/{skill-name}/SKILL.md` 파일이 생성되어 있음
