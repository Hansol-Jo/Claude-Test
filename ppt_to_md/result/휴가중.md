# 2. ERP 개선과제

## 2.1 FM 권한 프로세스 및 부문 정보 관리 개선

### 과제 정의

FM 조직권한 및 부문 정보 관리 효율화를 통해 사용자 권한 관련 문의를 감소시키는 과제입니다.

### 선정 배경

- 조직개편 또는 재원담당자 변경 시 GRC와 FM 간 권한 회수·신청 프로세스 재정립 필요
- 부문 정보 인터페이스 오류로 GRC 및 예산조정 신청 오류 발생
- 부문 정보의 자체 관리 필요성 증대

### 개선 내용

- GRC에서 권한 회수 후 FM 조직 권한을 재신청할 때 기존 조직 권한 삭제
- 대규모 조직개편 시 GRC를 통한 권한 신규·추가·변경 일괄 처리
- FM 내 조직별 부문 정보 자체 관리 로직 구현
- 요청자가 본인 부문 외 조직을 입력할 경우 오류 메시지 출력

### 기대 효과

- 대규모 조직개편 시 GRC를 통한 일괄 권한 변경
- 권한 변경에 따른 사용자 혼란 감소
- 부문 정보 자체 관리로 인터페이스 오류 감소

### KPI

| 구분 | 내용 |
|---|---|
| 현 수준 | 대량 권한 작업 최소 1~2주 소요, 부문정보 IF 2일 소요 |
| 목표 수준 | 개인·대량 권한 신청 실시간 반영, 부문정보 자체 관리(HR → FM) |
| 평가 방법 | ITSM 처리시간 단축 |
| 추진 일정 | 2013년 4월 ~ 6월 |

### AS-IS / TO-BE

| 구분 | AS-IS | TO-BE |
|---|---|---|
| 조직 코드 입력 | GRC 권한 신청 시 조직 코드 입력 오류 가능 | 본인 부문 외 조직 코드 입력 시 오류 메시지 |
| 대규모 조직개편 | GRC와 FM 권한 작업 이중화 | GRC에서 FM 기능·조직 권한 일괄 부여 |
| 권한 회수 후 재신청 | 기존 FM 조직 권한이 유지될 수 있음 | 신규 FM 조직 권한 신청 시 기존 조직 권한 삭제 |

### FMBDT 주요 기준

- 사용 원장: `9F` 지급예산
- 버전
  - `000`: 계획 / 실제 버전
  - `F01`: 연초 수립 예산 버전
- `ROBJNR` 값 존재: WBS 예산
- `ROBJNR` 값 없음: 조직 예산
- 프로세스
  - `ENTR`: 입력
  - `RECV`: 수신
  - `SEND`: 발신
  - `SUPL`: 증액
  - `RETN`: 감액
- 예산 유형
  - `BG01`: 예산
  - `RELE`: 릴리즈
  - `B1`: 예산
  - `R1`: 릴리즈
- `CB`로 시작: 사업직접비
- `ZBKT`: 사업직접비
- 금액 확인 시 주의사항
  1. 주로 `HSLXX` 필드 사용
  2. 실제 금액과 부호가 반대로 표시될 수 있음
  3. 금액이 100으로 나뉘어 표시됨  
     - 실제 금액: `1,000`
     - 테이블 표시: `-10.00`
