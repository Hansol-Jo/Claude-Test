# 매출/비용 Data 집계 Interface 운영 매뉴얼

## 개요

`ZCOBC0060`은 매출/비용 전표 데이터를 집계하는 결산 프로그램이다. 생성된 집계 데이터는 후속 결산 프로세스 `ZCOBC0062` 및 결산리포트 `ZCOBC9100`에서 사용된다.

- 사용 주체: 총괄회계팀
- 주요 목적
  - 관리회계 전표 데이터를 집계하여 `ZTCOB0010`에 저장
  - 집계 결과에 PA 특성항목을 반영하여 `ZTCOB0012` 생성
  - 결산리포트용 요약 및 상세전표 데이터 생성 배치 작업 실행
- 일반적인 결산 수행 방식: `일괄갱신` 실행조건에서 `신규집계` 작업 수행
- `오류항목 재집계`는 일반적으로 거의 수행하지 않음

## 기능: 매출/비용 전표 집계 실행

### 수행절차

1. T-Code `ZCOBC0060`을 실행한다.
2. 관리회계 영역을 확인한다.
   - 관리회계 영역은 `1000(㈜케이티)`로 고정된다.
3. 결산기준월을 입력한다.
4. 실행 목적에 따라 실행조건을 선택한다.
   - 실적 테이블 집계
   - 특성항목 갱신
   - 일괄갱신
5. 작업을 선택한다.
   - 신규집계
   - 오류항목 재집계
   - 조회
   - 계정단일화 원본데이터 조회
6. 프로그램을 실행한다.
7. 일반적인 결산 작업은 `일괄갱신` 조건에서 `신규집계`를 수행한다.

### 시스템 처리

- `실적 테이블 집계`는 매출/비용 계정 범위와 관리회계 전표 데이터를 기반으로 집계 결과를 생성한다.
- `특성항목 갱신`은 실적 테이블 집계 결과에 PA 특성항목을 반영하여 데이터를 생성한다.
- `일괄갱신`은 실적 테이블 집계와 특성항목 갱신 프로세스를 순차 수행하고, 이후 결산리포트용 상세전표 데이터 생성까지 연결한다.
- `신규집계` 또는 `오류항목 재집계` 수행 시 해당 실행조건에 따른 배치 작업이 생성된다.

### 처리 결과

- 실행조건 및 작업에 따라 다음 화면이 표시될 수 있다.

|실행조건 / 작업|표시 화면 또는 처리|
|-|-|
|신규집계, 오류항목 재집계|결산 구분 화면|
|실적 테이블 집계 이외 조건의 조회|데이터 라인 선택, 파일다운로드 화면|
|계정별 집계 실행조건|집계 대상 계정 선택 화면|
|일괄갱신 조회|라인아이템별 집계 및 특성정보를 포함한 ALV 조회|

### 업무 규칙

- 관리회계 영역은 `1000(㈜케이티)`로 고정이다.
- 결산기준월은 필수 입력 항목이므로 반드시 입력해야 한다.
- 보통 `일괄갱신` 실행조건에서 `신규집계` 작업을 수행한다.
- `오류항목 재집계` 작업은 일반적으로 거의 수행하지 않는다.

## 기능: 실적 테이블 집계

### 수행절차

1. `ZCOBC0060`에서 결산기준월을 입력한다.
2. 실행조건으로 `실적 테이블 집계`를 선택한다.
3. `신규집계` 또는 필요 시 `오류항목 재집계`를 선택한다.
4. 프로그램을 실행한다.
5. 집계 결과 및 생성된 배치 작업을 확인한다.

### 시스템 처리

1. 입력한 결산기준월에 대해 `ZTCOB0010`에 기존 데이터가 존재하는지 확인한다.
2. 매출/비용 계정범위 테이블 `ZTCOB0011`을 기준으로 추출 대상 계정 RANGE를 생성한다.
   - 저장된 계정 범위는 4계정(매출) 및 5계정(비용)의 전체 기간이다.
3. 관리회계 전표 테이블 `COEP`에서 라인아이템별 데이터를 추출한다.
   - 성능 이슈를 고려하여 추출 단계에서는 `APPEND` 처리하고, 이후 집계 데이터 편집 단계에서 `COLLECT` 처리한다.
4. 제외조건에 해당하는 전표 데이터를 별도로 추출하여 `ZRECND` 값을 수정한 후 반영한다.
5. 코스트센터, 단일화 조직, 프로젝트 마스터 데이터를 추출한다.
6. `OBJNR` 기준 CO 오브젝트 유형별로 집계 데이터를 편집한다.
7. 집계 결과를 `ZTCOB0010`에 저장한다.
8. 결산리포트용 요약 데이터 생성을 위해 `ZCOBC9200` 배치 작업을 등록·실행한다.

### 처리 결과

- 실적 테이블 집계 결과는 `ZTCOB0010`에 저장된다.
- 조회 시 `ZTCOB0010`에 저장된 데이터 중 `errflag='S'`인 데이터를 확인할 수 있다.
- 결산리포트 `ZCOBC9100` 조회용 요약 데이터 생성을 위해 `ZCOBC9200`이 백그라운드 배치 작업으로 실행된다.
- 배치 등록 결과 로그는 `ZTCOB0028`에 저장된다.

### 업무 규칙

- 입력 결산기준월에 대한 기존 `ZTCOB0010` 데이터가 있으면 전체 삭제 후 집계를 진행한다.
- 집계 결과 저장 시 대량 메모리 사용 문제를 방지하기 위해 10만 건 단위로 `INSERT`한다.
- 제외 전표유형은 `GZ`, `X7`, `GA`이다.
- IFRS15 관련 CO 재전기 전표 항목은 별도 처리 대상으로 추출하여 `ZRECND` 값을 수정한다.
- IFRS15 가계정 전표내역 추출 및 부동산 관련 전표내역 추출 로직은 현재 불필요한 로직으로 표시되어 있다.
- `오류항목 재집계`는 `errflag='E'`인 항목을 대상으로 집계 프로세스를 다시 수행한다.

## 기능: CO 오브젝트 유형별 집계 데이터 편집

### 수행절차

1. `COEP`에서 추출한 라인아이템 데이터를 CO 오브젝트 유형(`OBJNR`)별로 구분한다.
2. 오브젝트 유형에 따라 프로젝트, 전표유형, 통계 오브젝트 여부 등을 반영하여 집계 데이터를 편집한다.
3. 편집된 데이터를 집계 결과로 저장한다.

### 시스템 처리

|CO 오브젝트 유형|시스템 처리|
|-|-|
|`EO` 오브젝트(수익성 세그먼트)|통계 PTJ인 Internal PTJ(`PROFL='ZPS9000'`)을 추가 집계|
|`IB`, `IM`, `IS` 오브젝트|부동산 관련 오브젝트이며 사용하지 않음|
|`KS` 오브젝트(코스트센터)|통계 PTJ인 Internal PTJ(`PROFL='ZPS9000'`)을 추가 집계|
|`OR` 오브젝트(오더)|전표유형 차이로 `COLLECT`가 불가한 경우 전표유형을 SPACE로 처리|
|`PR` 오브젝트(WBS)|전표유형 차이로 `COLLECT`가 불가한 경우 전표유형을 SPACE로 처리|
|`OTHERS`|가계정이며 현재 데이터가 없음|

### 처리 결과

- CO 오브젝트 유형별 특성을 반영한 집계 데이터가 생성된다.
- WBS가 코스트센터로 정산된 경우 상위 프로젝트 정보를 추출하여 저장한다.

### 업무 규칙

- WBS가 CC로 정산된 경우(`PAROB='PR'` 및 `VRGNG='KOAO'`) 상위 프로젝트를 추출하여 저장한다.
- 통계 WBS는 집계하지 않는다(`XSTAT='X'`).
- 단일화 처리 시 EO 오브젝트(수익성 세그먼트)를 KS 오브젝트(코스트센터)로 변경하며, 수익성 세그먼트는 제거된다.
- 단일화 처리는 FI 결산 시 수행된다.

## 기능: 특성항목 갱신

### 수행절차

1. `ZCOBC0060`에서 결산기준월을 입력한다.
2. 실행조건으로 `특성항목 갱신`을 선택한다.
3. `신규집계` 또는 필요 시 `오류항목 재집계`를 선택한다.
4. 프로그램을 실행한다.
5. `ZTCOB0012` 생성 결과 및 후속 배치 작업을 확인한다.

### 시스템 처리

1. 입력 결산기준월의 `ZTCOB0012` 기존 데이터 존재 여부를 확인한다.
2. 프로젝트 마스터(`PRPS`, `PROJ`) 및 단일화 조직 데이터(`ZTFIR0050`)를 기준 데이터로 추출한다.
3. 수익성 세그먼트 번호를 기준으로 `CE41000`에서 PA 특성을 조회한다.
4. EO 오브젝트에 대해서만 PA 특성 데이터를 반영한다.
5. EO 이외 오브젝트는 원 데이터를 유지하여 `APPEND`한다.
6. `ZTCOB0012` 저장용 데이터를 생성한다.
7. EO 오브젝트로 결정된 CC/PC 정보를 `ZTCOB0010`에 `UPDATE`한다.
8. 계정 단일화 처리 및 WBS 관련 추가 처리를 수행한다.
9. 원본 데이터를 검증 목적으로 `ZTCOB0014`에 백업한다.
10. 생성 데이터를 `ZTCOB0012`에 10만 건 단위로 저장한다.
11. `ZCOBC9200` 배치 작업을 실행한다.

### 처리 결과

- PA 특성이 반영된 집계 데이터가 `ZTCOB0012`에 저장된다.
- EO 오브젝트 기준으로 결정된 CC/PC는 `ZTCOB0010`에 반영되며, 매출비용 집계 결과 점검 프로그램 `ZCOBC0160`에서 사용된다.
- 계정단일화 전 원본 데이터는 `ZTCOB0014`에 저장되어 검증에 사용된다.
- 결산리포트용 요약 데이터 생성을 위한 `ZCOBC9200` 배치 작업이 실행된다.

### 업무 규칙

- 입력한 결산기준월에 대한 `ZTCOB0012` 기존 데이터가 있으면 전체 삭제 후 진행한다.
- PA 특성은 EO 오브젝트에만 반영한다.
- 기타매출 계정 `0417*`은 전표상 BM이 입력되지 않지만, EDW에서는 매출인식 조건에 포함되므로 특정 BM을 하드코딩한다.
- 계정단일화 처리 시 EO 오브젝트를 KS 오브젝트로 변환하여 `ZTCOB0012` 데이터를 생성한다.
- WBS 특성 중 Real WBS는 제외 처리하며, 계정과 특성은 유지한다.
- CO 재전기 전표는 제외 처리한다.
- 단일화 조직에 Internal 프로젝트가 존재하는 경우 다음 전표를 생성한다.
  1. KS로 변경하고 단일화계정으로 차감전표 생성
  2. KS로 변경하고 단일화계정 및 WBS를 반영한 추가전표 생성
- `ZTCOB0012` 저장은 10만 건 단위로 수행한다.

## 기능: 일괄갱신

### 수행절차

1. `ZCOBC0060`에서 결산기준월을 입력한다.
2. 실행조건으로 `일괄갱신`을 선택한다.
3. 작업으로 `신규집계`를 선택한다.
4. 프로그램을 실행한다.
5. 실적 테이블 집계 및 특성항목 갱신 완료 여부를 확인한다.
6. 결산리포트용 요약 데이터 생성 배치의 종료 상태를 확인한다.
7. 요약 데이터 생성이 완료되면 결산리포트용 상세전표 데이터 생성 배치를 실행한다.

### 시스템 처리

1. 실적 테이블 집계 프로세스를 수행한다.
2. 결산리포트용 요약 데이터 생성 배치를 백그라운드에서 실행한다.
3. 특성항목 갱신 프로세스를 수행한다.
4. 특성항목 갱신에 따른 요약 데이터 생성 배치를 실행한다.
5. 배치 작업 상태 테이블 `TBTCO`에서 요약 데이터 생성 배치의 종료 상태를 확인한다.
6. 배치 상태가 완료(`STATUS='F'`)이면 결산리포트용 상세전표 데이터 생성 배치를 실행한다.

### 처리 결과

- `ZTCOB0010` 및 `ZTCOB0012` 집계 데이터가 생성된다.
- 결산리포트용 요약 데이터와 상세전표 데이터 생성 작업이 순차적으로 실행된다.
- 결산리포트 `ZCOBC9100`에서 집계 결과를 조회할 수 있도록 후속 데이터가 생성된다.

### 업무 규칙

- 일괄갱신은 실적 테이블 집계, 특성항목 갱신, 요약 데이터 생성, 상세전표 데이터 생성을 순차적으로 수행한다.
- 요약 데이터 생성 배치가 완료 상태(`TBTCO-STATUS='F'`)인 경우에만 상세전표 데이터 생성 배치를 실행한다.
- 일반적인 결산 시 `일괄갱신`의 `신규집계` 작업을 사용한다.

## 기능: 집계 결과 조회 및 다운로드

### 수행절차

1. `ZCOBC0060`에서 결산기준월을 입력한다.
2. 실행조건을 선택한다.
   - 실적 테이블 집계
   - 특성항목 갱신
   - 일괄갱신
3. 작업으로 `조회`를 선택한다.
4. 필요 시 데이터 라인 선택 또는 파일다운로드 기능을 사용한다.
5. ALV 결과에서 집계 데이터와 관리계정 관련 정보를 확인한다.

### 시스템 처리

- `실적 테이블 집계` 조회 시 `ZTCOB0010`의 `errflag='S'` 데이터를 조회한다.
- `특성항목 갱신` 및 `일괄갱신` 조회 시 `CE41000`에서 추출된 특성 데이터가 저장된 `ZTCOB0012` 데이터를 조회한다.
- 전표유형명 확인을 위해 `T003T`를 조회한다.
- 계정별 특성그룹 확인을 위해 `TKEP9`, `ZTCOB0180`을 조회한다.
- CO 오브젝트에 따라 BM, 고객, 채널, COP, 대리점, IT표준서비스 등의 특성을 조회 결과에 반영한다.
- 관리계정 관리 데이터에 해당하는 원가요소의 경우 ALV에서 관리계정, 관리계정명, 인식/상각 여부를 표시한다.

### 처리 결과

- 집계 대상 라인아이템 및 특성항목을 ALV에서 확인할 수 있다.
- 조건에 따라 데이터 라인 선택 및 파일다운로드 화면이 표시된다.
- 관리계정 관리 대상 원가요소는 관리계정 관련 정보와 함께 확인할 수 있다.

### 업무 규칙

- `실적 테이블 집계`를 수행하지 않은 상태에서 특성항목 갱신 조회 건수를 확인하면 `ZTCOB0012` 건수와 총 금액은 0으로 표시된다.
- `실적 테이블 집계`, `특성항목 갱신`, `일괄갱신` 조건에서 조회 화면은 유사하게 표시된다.
- 실적 테이블 집계 외의 실행조건에서 `조회`를 선택하면 데이터 라인 선택 및 파일다운로드 화면이 표시된다.

## 기능: 특성항목 갱신 조회 건수 확인

### 수행절차

1. `ZCOBC0060`에서 결산기준월을 입력한다.
2. **특성항목 갱신 조회 건수 확인** 버튼을 클릭한다.
3. 해당 결산기준월의 `ZTCOB0012` 건수 및 총 금액을 확인한다.

### 시스템 처리

- 지정한 결산기준월을 기준으로 `ZTCOB0012`의 건수와 총 금액을 조회한다.

### 처리 결과

- 해당 결산기준월에 대한 `ZTCOB0012` 데이터 건수와 총 금액이 표시된다.

### 업무 규칙

- `실적 테이블 집계` 및 `특성항목 갱신` 조건으로 집계를 수행한 경우 `ZTCOB0012`에 데이터가 집계된다.
- 집계를 수행하지 않은 경우 조회 건수와 총 금액은 0으로 표시된다.

## 기능: 계정정보 관리

### 수행절차

1. `ZCOBC0060` 화면에서 **계정정보 관리** 버튼을 클릭한다.
2. 관리계정 정보관리 유지보수 뷰에서 계정 정보를 확인 또는 관리한다.

### 시스템 처리

- 매출/비용 계정별 인식/상각 여부와 관리계정 정보를 관리한다.
- `일괄갱신` 조건에서 `조회`를 수행할 때, 라인아이템의 원가요소가 관리계정 관리 대상인 경우 관련 정보를 ALV에 표시한다.

### 처리 결과

- 관리계정 정보관리 유지보수 뷰가 표시된다.
- ALV 조회 결과에 관리계정, 관리계정명, 인식/상각 여부가 표시된다.

### 업무 규칙

- 관리계정 정보는 매출/비용 계정별 인식/상각 여부 및 관리계정 관리에 사용된다.

## 기능: 계정단일화 원본데이터 조회

### 수행절차

1. `ZCOBC0060`에서 작업으로 `계정단일화 원본데이터 조회`를 선택한다.
2. 프로그램을 실행한다.
3. 원본데이터 테이블 `ZTCOB0014`에 백업된 데이터를 조회한다.

### 시스템 처리

- 단일화 조직 관리 테이블 `ZTFIR0050`에 등록된 조직(`ORGEH`)으로 유입된 전표 요소를 해당 조직의 계정(`HKONT`)으로 단일화한다.
- 단일화 처리 전 원본 데이터를 `ZTCOB0014`에 백업한다.
- 사용자는 `ZTCOB0014`를 통해 집계 전 원본 데이터를 확인할 수 있다.

### 처리 결과

- 계정단일화 이전의 원본 전표 데이터를 확인할 수 있다.

### 업무 규칙

- 단일화 조직에 해당하는 전표 요소는 해당 조직의 단일화 계정으로 처리된다.
- 원본 데이터는 단일화 처리 및 집계 결과 검증 목적으로 보관된다.

## 기능: 프로젝트별 BM 조회

### 수행절차

1. T-Code `ZCOBC0060A`를 실행한다.
2. 관리회계 영역 `1000(㈜케이티)`를 확인한다.
3. 결산기준월을 입력한다.
4. 조회할 프로젝트 코드를 검색조건에 입력한다.
5. 프로그램을 실행한다.
6. 프로젝트별 BM L4 조회 결과를 확인한다.

### 시스템 처리

1. `ZTCOB0012`에서 프로젝트 관련 집계 데이터를 확인한다.
2. `ZTPSP1380(PPM)`에서 프로젝트 정보를 확인한다.
3. 프로젝트별 BM L4를 출력한다.

### 처리 결과

- 매출/비용 전표 집계 데이터에 존재하는 프로젝트별 BM L4를 조회할 수 있다.

### 업무 규칙

- 관리회계 영역은 `1000(㈜케이티)`로 고정이다.
- 결산기준월은 필수 입력 항목이므로 반드시 입력해야 한다.
- 프로젝트 코드를 검색조건으로 입력하여 조회한다.
