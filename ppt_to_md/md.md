# 매출/비용 Data 집계 Interface

## 개요

- `ZCOBC0060`은 매출/비용 전표 데이터를 집계하는 결산 프로그램이다.
- 생성된 집계 데이터는 후속 결산 프로세스 `ZCOBC0062` 및 결산리포트 `ZCOBC9100`에서 사용한다.
- 사용 주체는 총괄회계팀이다.
- 일반적으로 실행조건 `일괄갱신`에서 작업 `신규집계`를 수행한다.
- `오류항목 재집계`는 `errflag='E'` 항목을 대상으로 집계 프로세스를 다시 수행한다.

(출처: slide 1, 7)

## 메뉴 정보

- 프로그램명: `ZCOBC0060`
- 메뉴명: [확인필요]
- 화면명: 매출/비용 Data 집계 Interface
- T-Code: `ZCOBC0060`
- 관리회계 영역: `1000(㈜케이티)` 고정
- 필수 입력항목: 결산기준월

(출처: slide 1)

## 기능: 매출/비용 집계 실행

### 수행절차

1. T-Code `ZCOBC0060`을 실행한다.
2. 관리회계 영역 `1000(㈜케이티)`을 확인한다.
3. 결산기준월을 입력한다.
4. 실행 목적에 따라 실행조건을 선택한다.
   - 실적 테이블 집계
   - 특성항목 갱신
   - 일괄갱신
   - 계정별 집계 실행조건 [화면명/정확한 조건명 확인필요]
5. 작업을 선택한다.
   - 신규집계
   - 오류항목 재집계
   - 조회
   - 계정단일화 원본데이터 조회
6. 프로그램을 실행한다.

### 시스템 처리

- `신규집계` 또는 `오류항목 재집계`를 수행하면 결산 구분 화면이 표시된다.
- `조회` 작업은 `실적 테이블 집계` 외의 실행조건에서 수행 시 데이터 라인 선택 및 파일다운로드 화면을 표시한다.
- 계정별 집계 실행조건을 선택하면 집계 대상 계정 선택 화면을 표시한다.
- 집계 처리 완료 후 결산리포트 데이터를 생성하기 위해 `ZCOBC9200`을 백그라운드 Batch Job으로 실행한다.

### 처리 결과

- 실적 테이블 집계 결과는 `ZTCOB0010`에 저장된다.
- 특성항목 갱신 결과는 `ZTCOB0012`에 저장된다.
- 결산리포트 `ZCOBC9100`용 집계 데이터는 `ZCOBC9200`이 생성한다.

### 업무 규칙

- 관리회계 영역은 `1000(㈜케이티)`로 고정이다.
- 결산기준월은 반드시 입력해야 한다.
- 일반적으로 `일괄갱신` 조건에서 `신규집계` 작업을 수행한다.
- `오류항목 재집계`는 거의 수행하지 않는다.
- `오류항목 재집계`는 `errflag='E'`인 항목만 재처리한다.

## 기능: 실적 테이블 집계

### 수행절차

1. 입력한 결산기준월 기준으로 `ZTCOB0010`의 기존 데이터를 확인한다.
2. 매출/비용 계정범위 테이블 `ZTCOB0011`을 기준으로 추출 대상 계정 RANGE를 생성한다.
3. 관리회계 전표 테이블 `COEP`에서 라인아이템 데이터를 추출한다.
4. 제외조건 대상 전표 데이터를 별도로 추출하고 `ZRECND` 값을 수정한다.
5. 코스트센터, 단일화 조직, 프로젝트 마스터 데이터를 추출한다.
6. CO 오브젝트 타입별로 집계 데이터를 편집한다.
7. 집계 결과를 `ZTCOB0010`에 저장한다.
8. 결산리포트용 요약 데이터 생성을 위한 `ZCOBC9200` Batch Job을 등록·실행한다.

### 시스템 처리

- `ZTCOB0011`의 매출/비용 계정범위를 이용하여 추출 계정 리스트를 생성한다.
  - 4계정: 매출
  - 5계정: 비용
- `COEP`에서 라인아이템 단위로 데이터를 추출하여 APPEND한다.
- 성능 이슈로 라인아이템 추출 단계에서는 `COLLECT`하지 않고, 이후 집계 데이터 편집 단계에서 `COLLECT`한다.
- 대상 기간에 대한 기존 `ZTCOB0010` 데이터가 존재하면 기존 데이터를 전체 삭제한 후 집계를 진행한다.
- 집계 결과는 대량 메모리 사용을 방지하기 위해 10만 건 단위로 INSERT한다.

### 처리 결과

- 매출/비용 전표 집계 데이터가 `ZTCOB0010`에 저장된다.
- `ZTCOB0010`에서 `errflag='S'`인 데이터를 조회할 수 있다.
- 결산리포트 `ZCOBC9100` 조회용 요약 데이터 생성 Batch Job이 실행된다.

### 업무 규칙

- 전표유형 `GZ`, `X7`, `GA`는 제외조건 대상이다.
- IFRS15 관련 CO 재전기 전표 항목은 제외조건 대상이다.
- 제외조건 대상 전표는 별도로 추출하여 `ZRECND`(인식/상각) 값을 수정한다.
- 통계 WBS는 집계하지 않는다. (`XSTAT='X'`)
- WBS가 코스트센터로 정산된 경우 `PAROB='PR'` 및 `VRGNG='KOAO'` 조건에 따라 상위 프로젝트를 추출·저장한다.
- OR 오브젝트 및 PR 오브젝트는 전표유형 차이로 `COLLECT`되지 않는 경우를 방지하기 위해 전표유형을 SPACE로 처리한다.
- IFRS15 가계정 전표 및 부동산 관련 전표 추출 로직은 현재 불필요한 로직으로 표시되어 있다.

(출처: slide 6-7, 11-21)

## 기능: CO 오브젝트별 집계 데이터 편집

### 수행절차

1. `COEP`에서 추출한 라인아이템의 CO 오브젝트 타입(`OBJNR`)을 확인한다.
2. 오브젝트 타입별 처리 규칙에 따라 집계 데이터를 편집한다.
3. 편집된 데이터를 집계 결과에 반영한다.

### 시스템 처리

- EO 오브젝트(수익성 세그먼트)는 통계 PTJ인 Internal PTJ(`PROFL='ZPS9000'`)를 추가 집계한다.
- KS 오브젝트(코스트센터)는 통계 PTJ인 Internal PTJ(`PROFL='ZPS9000'`)를 추가 집계한다.
- OR 오브젝트(오더)와 PR 오브젝트(WBS)는 전표유형을 SPACE로 처리할 수 있다.
- IB, IM, IS 오브젝트(부동산 관련)는 사용하지 않는다.
- OTHERS는 가계정이며 현재 데이터가 없는 것으로 설명되어 있다.

### 업무 규칙

- 단일화 처리 시 EO 오브젝트(수익성 세그먼트)를 KS 오브젝트(코스트센터)로 변경하고 수익성 세그먼트를 제거한다.
- 통계 WBS는 집계 대상에서 제외한다. (`XSTAT='X'`)
- EO 및 KS 오브젝트의 Internal PTJ 추가 집계는 `PROFL='ZPS9000'` 조건을 사용한다.

(출처: slide 17, 19)

## 기능: 특성항목 갱신

### 수행절차

1. 입력한 결산기준월에 대한 `ZTCOB0012` 기존 데이터를 확인한다.
2. 프로젝트 마스터 `PRPS`, `PROJ` 및 단일화 조직 테이블 `ZTFIR0050`에서 기준 데이터를 추출한다.
3. 수익성세그먼트 번호를 기준으로 `CE41000`에서 PA 특성을 조회한다.
4. 실적 테이블 집계 결과에 특성항목을 반영한다.
5. 계정 단일화 처리 및 원본 데이터 백업을 수행한다.
6. 결과 데이터를 `ZTCOB0012`에 저장한다.
7. 결산리포트용 상세전표 데이터 생성을 위한 `ZCOBC9200` Batch Job을 등록·실행한다.

### 시스템 처리

- `ZTCOB0012`에 대상 기간 기존 데이터가 있으면 전체 삭제 후 처리한다.
- EO 오브젝트에 대해서만 `CE41000`의 수익성세그먼트(PSEG) 특성을 반영한다.
- EO 외 오브젝트는 기존 데이터를 그대로 APPEND한다.
- EO 오브젝트로 결정된 CC/PC를 `ZTCOB0010`에 UPDATE한다.
- 원본 데이터는 검증 목적으로 `ZTCOB0014`에 백업한다.
- 모든 처리 완료 후 `ZTCOB0012`에 10만 건 단위로 INSERT한다.

### 처리 결과

- PA 특성이 반영된 매출/비용 집계 데이터가 `ZTCOB0012`에 저장된다.
- `ZTCOB0010`의 CC/PC 정보가 갱신되며, 이는 매출 비용 집계 결과 점검 프로그램 `ZCOBC0160`에서 사용한다.
- 단일화 전 원본 데이터는 `ZTCOB0014`에서 검증할 수 있다.
- 결산리포트용 상세전표 데이터 생성 Batch Job이 실행된다.

### 업무 규칙

- EO 오브젝트에만 PA 특성을 반영한다.
- 기타매출 `0417*` 계정은 전표상 BM을 입력하지 않지만 EDW 매출인식 조건에 포함되므로 특정 BM을 하드코딩한다.
- 계정 단일화 처리 시 EO 오브젝트를 KS 오브젝트로 변환하여 `ZTCOB0012` 데이터를 생성한다.
- Real WBS인 경우 제외 처리하며, 계정 및 특성은 유지한다.
- CO 재전기 전표는 제외 처리한다.
- 단일화 조직에 Internal 프로젝트가 존재하면 다음 전표를 생성한다.
  1. KS로 변경한 단일화계정 차감전표
  2. KS로 변경하고 단일화계정 및 WBS를 추가한 추가전표

## 기능: 일괄갱신

### 수행절차

1. 실적 테이블 집계 프로세스를 수행한다.
2. 결산리포트용 요약 데이터 생성 Batch Job을 실행한다.
3. 특성항목 갱신 프로세스를 수행한다.
4. 요약 데이터 생성 Batch Job의 종료 상태를 확인한다.
5. 요약 데이터 생성이 완료되면 결산리포트용 상세전표 데이터 생성 Batch Job을 실행한다.

### 시스템 처리

- 배치작업 상태 테이블 `TBTCO`에서 백그라운드 작업의 완료 여부를 확인한다.
- Batch Job 상태가 `STATUS='F'`이면 결산리포트용 상세전표 데이터 생성 Batch Job을 실행한다.

### 처리 결과

- 실적 테이블 집계, 특성항목 갱신, 결산리포트용 요약 데이터 생성 및 상세전표 데이터 생성을 순차 수행한다.

### 업무 규칙

- 결산리포트용 상세전표 데이터 생성은 요약 데이터 생성 Batch Job이 완료된 후 수행한다.
- Batch Job 완료 여부는 `TBTCO.STATUS='F'`로 확인한다.

## 기능: 집계 데이터 조회

### 수행절차

1. 실행조건에서 `실적 테이블 집계`, `특성항목 갱신` 또는 `일괄갱신`을 선택한다.
2. 작업으로 `조회`를 선택한다.
3. 필요 시 데이터 라인 선택 또는 파일다운로드를 수행한다.

### 시스템 처리

- `실적 테이블 집계` 조건에서는 `ZTCOB0010`의 `errflag='S'` 데이터를 조회한다.
- `특성항목 갱신` 및 `일괄갱신` 조건에서는 CO 오브젝트에 따라 `CE41000`에서 추출한 특성 데이터가 저장된 `ZTCOB0012` 데이터를 조회한다.
- 전표유형명 확인을 위해 `T003T`를 조회한다.
- 계정별 특성그룹 확인을 위해 `TKEP9`, `ZTCOB0180`을 조회한다.
- 조회 결과에서는 CO 오브젝트에 따라 BM, 고객, 채널, COP, 대리점, IT표준서비스 등의 특성을 확인할 수 있다.

### 처리 결과

- 집계된 매출/비용 전표 데이터와 특성항목 데이터를 조회한다.
- `일괄갱신`-`조회` 수행 시 라인아이템 원가요소가 관리계정 관리 데이터이면 관리계정, 관리계정명, 인식/상각 여부를 ALV에서 표시한다.

(출처: slide 5-6)

## 기능: 특성항목 갱신 조회 건수 확인

### 수행절차

1. `특성항목 갱신 조회 건수 확인` 버튼을 클릭한다.
2. 대상 결산기준월의 집계 건수 및 총 금액을 확인한다.

### 시스템 처리

- `ZTCOB0012`에서 대상 결산기준월의 건수와 총 금액을 조회한다.

### 처리 결과

- 해당 결산기준월의 `ZTCOB0012` 건수와 총 금액이 표시된다.
- `실적 테이블 집계`와 `특성항목 갱신`을 수행한 `일괄갱신` 결과가 없으면 건수와 총 금액은 0으로 표시된다.

### 업무 규칙

- 집계를 수행하지 않은 상태에서 버튼을 클릭하면 건수와 총 금액은 0이다.

## 기능: 계정정보 관리

### 수행절차

1. `계정정보 관리` 버튼을 클릭한다.
2. 관리계정 정보관리 유지보수 뷰에서 매출/비용 계정별 정보를 관리한다.

### 시스템 처리

- 매출/비용 계정별 인식/상각 여부 및 관리계정을 관리한다.
- `일괄갱신`-`조회` 시 라인아이템 원가요소가 관리계정 관리 데이터이면 관련 정보를 ALV에 표시한다.

### 처리 결과

- 관리계정, 관리계정명, 인식/상각 여부를 조회·관리할 수 있다.

(출처: slide 5)

## 기능: 계정단일화 원본데이터 조회

### 수행절차

1. 작업으로 `계정단일화 원본데이터 조회`를 선택한다.
2. 원본데이터 테이블 `ZTCOB0014`의 백업 데이터를 조회한다.

### 시스템 처리

- 단일화 조직 관리 테이블 `ZTFIR0050`에 등록된 조직(`ORGEH`)으로 유입된 전표 요소는 해당 조직의 계정(`HKONT`)으로 단일화한다.
- 집계 시 단일화 전 원본 데이터를 `ZTCOB0014`에 백업한다.

### 처리 결과

- 계정 단일화 이전의 원본 데이터를 검증 목적으로 확인할 수 있다.

### 업무 규칙

- `ZTFIR0050`에 등록된 조직(`ORGEH`)에 유입된 전표 요소는 지정 계정(`HKONT`)으로 단일화된다.

## 기능: 프로젝트별 BM 조회

### 메뉴 정보

- 프로그램명: `ZCOBC0060`
- 메뉴명: [확인필요]
- 화면명: 프로젝트별 BM 조회
- T-Code: `ZCOBC0060A`
- 관리회계 영역: `1000(㈜케이티)` 고정
- 필수 입력항목: 결산기준월
- 사용 주체: 총괄회계팀

### 수행절차

1. T-Code `ZCOBC0060A`를 실행한다.
2. 관리회계 영역 `1000(㈜케이티)`을 확인한다.
3. 결산기준월을 입력한다.
4. 검색조건에 조회할 프로젝트 코드를 입력한다.
5. 프로그램을 실행한다.

### 시스템 처리

1. `ZTCOB0012`에서 프로젝트 관련 집계 데이터를 확인한다.
2. `ZTPSP1380(PPM)`에서 프로젝트 정보를 확인한다.
3. 프로젝트별 BM L4를 출력한다.

### 처리 결과

- 매출/비용 전표 집계 데이터에 존재하는 프로젝트별 BM L4를 조회한다.

### 업무 규칙

- 관리회계 영역은 `1000(㈜케이티)`로 고정이다.
- 결산기준월은 반드시 입력해야 한다.
